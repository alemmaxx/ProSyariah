# Sandaran manual senarai SC

Jika robot gagal memuat turun senarai patuh syariah dari laman SC, muat turun PDF
"List of Shariah-Compliant Securities" sendiri dari sc.com.my dan muat naik ke folder ini
(Add file → Upload files). Robot akan berjalan sendiri, membaca fail terbaharu di sini,
dan menyebarkannya kepada semua pengguna app.
